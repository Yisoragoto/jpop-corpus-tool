## 实现差异

mac 使用 AVAudioFile → AVAudioPlayerNode → AVAudioUnitTimePitch → mixer。速度和音高分别设定，变调不生成文件，因此没有缓存目录、缓存限额或离线渲染等待状态。调音会跨曲目保留，重启恢复原速原调。文件解码交给系统，支持 FLAC / MP3 / AAC；不改 Rust 或 FFI。

第 4 阶段核对 PitchCacheCard / pitchCache.ts：Windows 的预生成、占用统计、清理、生成进度与失败缓存状态针对离线变调文件。
mac 实时变调没有这些文件，因此不移植磁盘缓存卡片、任务状态或对应 FFI，也不显示无效的清理/生成按钮；变调档位和播放行为继续与 Windows 一致。

歌词、循环和试听使用源音频秒数。位置约每 50ms 发布；音频回调只处理采样和受锁保护的频谱结果，界面状态在 MainActor 更新。测试用协议替身，不启动声卡。真实设备解码和时间伸缩由 CI smoke 验证位置推进，实际听感仍需 Mac 人工验收。

Windows 手动翻歌词后在下一次换行恢复跟随；mac 按本阶段的交互要求等待 4 秒恢复，暂停时也会回到当前行。大窗口的进度与走带放在左侧封面下，小窗口或查词侧栏打开时改用底部播放条。侧栏宽度受窗口可用空间约束。

## 快捷键

| 按键 | 行为 |
|---|---|
| 空格 / ⌥空格 | 播放 / 暂停 |
| ← / → | 后退 / 前进 5 秒 |
| ↑ / ↓ | 音量增加 / 减少 5% |
| ⌥⌘↑ / ⌥⌘↓ | 上一行 / 下一行 |
| ⌘L | 循环当前行 / 取消循环 |
| ⌘Y | 显示 / 隐藏歌词面板 |
| ⌘⇧F | 打开 / 退出全屏歌词 |
| ⌘⇧R | 振假名开关 |
| F11 | 当前窗口进入 / 退出原生全屏 |
| Esc | 优先关闭弹层 / 编辑器，其次退出舞台 |

输入框保留空格与方向键；滑块、列表和键盘聚焦按钮保留其原生按键。打轴窗口沿用第 1 阶段的空格打点及方向键选字，优先于播放快捷键。原播放条的上一行 / 下一行图标改用 Windows 的前后 5 秒语义，原行级快捷键不变。Windows 的 Ctrl/Cmd+K 搜索沿用 mac 的 ⌘K；命令面板在第 4 阶段接入 ⌘P，并与搜索共用浮层。

## 视觉参考和验证

采用 Music.app 的大封面、两栏正在播放、白色实心 SF Symbols、细进度轨道、悬停玻璃圈及交叉淡入。背景使用模糊渐变圆，兼容 macOS 14 / Xcode 15.4，不使用 MeshGradient 或 glassEffect。未引用 Petrichor 代码，无新增第三方署名。

本机 Windows 无法编译 Swift。必须在 macos-14 CI 运行 swift build、swift test、SourceGuardTests 及真实 FLAC 的变调 / 倍速 smoke，检查截图与 smoke.txt；不能把本机静态复查当作已通过 Swift 编译。

| 验证 | 本阶段结果 |
|---|---|
| git diff --check | 本机通过 |
| SourceGuards.swift 同规则的 Python 静态检查 | 本机通过：55 个源文件、68 个 View；每个 View 至多一个 fileImporter / sheet / alert，导入失败显式处理 |
| 档位、频谱条数、smoke 与 CI 检查名称一致性 | 本机通过；RATE_STEPS 完全相同、−6…+6 半音、48 条 |
| PlayerModelTests（8 项） | 已新增，未在 Windows 执行：5 秒边界、音量与静音持久化、档位 / 重置、时长和设置、各速度 / 音调下循环与试听、历史与错误、真实单位末尾保护、曲末循环与暂停竞态 |
