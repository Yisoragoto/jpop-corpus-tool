# Bug 跟踪

一个 bug 一份 `bugs/NNNN-slug.md`，先记录复现，再做根因修复和回归测试。
**两个勾没打满不算修完**：根因修复和自动化测试必须都附上实际提交或测试路径。

在仓库根运行 `./scripts/bug.ps1 new <slug>` 建档；分支合并造成重号时运行
`./scripts/bug.ps1 renumber`；合并完成运行 `./scripts/bug.ps1 settle` 重排并刷新索引。
编号只是索引，引用 bug 时同时写 slug；重排按修改时间（相同时按文件名），不会删记录。
索引的状态由两个勾决定，提交栏从修复行里的提交哈希提取。不要手改索引行。
