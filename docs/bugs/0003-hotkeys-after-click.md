# BUG-0003 鼠标点过按钮后快捷键失灵

- 发现：2026-10-23 / 版本 0.3.3 之后的 main / Windows WebView2
- 现象：用鼠标点过播放键、歌词里的词之类的按钮之后，←→ 快进快退、↑↓ 音量都没反应；焦点在歌词的词上按空格会再查一次词，而不是暂停。
- 复现步骤：放一首歌，用鼠标点一下播放条的播放键，再按 →。进度不动。
- 根因：`app/src/useHotkeys.ts` 修 BUG-0001 时把「焦点在任何按钮或带 tabindex 的元素上」都当成不该接全局快捷键；鼠标点过的按钮焦点会一直停在上面，于是所有快捷键都让给了它。
- 影响面：播放条、歌词、词云、KWIC 列表点过之后的全部键盘快捷键。
- 修复：☑ 根因修复（与本档案同一提交；`keepsKey`：输入框留全部键，滑块留方向键，只有用键盘移过去的按钮才留空格 / 回车；鼠标点出来的焦点自己记，不能在 keydown 里问 `:focus-visible`，按键那一刻它总是真） ☑ 自动化测试（`app/src/useHotkeys.test.ts`；BUG-0001 的 Tab + Space 场景仍由 `scripts/smoke.mjs` keyboard 覆盖）
- 清理条件：无临时兼容层
