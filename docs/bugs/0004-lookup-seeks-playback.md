# BUG-0004 点词查词会跳播放进度

- 发现：2026-10-23 / 版本 0.3.3 之后的 main / 全平台
- 现象：正在放的这首歌里点一个词查词典，播放进度会跳到这个词（没有逐字时间时跳回行首）；全屏里原来「点词不跳」。
- 复现步骤：放一首歌，等它唱到第十行，点第三行里的一个词。进度跳回第三行。
- 根因：`app/src/pages/LibraryPage.tsx` 的 `renderLineText` 在词的 onClick 里先调 `seekToken()` 再查词；`LyricUnit` 的每个字也带跳转。
- 影响面：曲库歌词和全屏歌词里的查词。
- 修复：☑ 根因修复（与本档案同一提交；点词只查词，跳转只走行首的时间按钮和全屏里点行；去掉 `LyricUnit`） ☑ 自动化测试（`app/src/useKaraoke.test.ts` 的点亮测试覆盖改后的字 span；查词不跳由 release 版实测确认）
- 清理条件：无临时兼容层
