# BUG-0005 有逐字时间的歌整首每个字都拆成组件

- 发现：2026-10-23 / 版本 0.3.3 之后的 main / 全平台
- 现象：有逐字时间的歌，整首每一行的每个字都渲染成一个组件；关掉「逐字点亮」后页面结构也和原来不一样。
- 复现步骤：采用一份逐字歌词，在开发者工具里数 `.lyric-unit`，是全曲字数。
- 根因：`app/src/pages/LibraryPage.tsx` 的 `chars()` 对所有有时间轴的行都拆字（`unitTimeline !== null`），而曲库页随播放轮询每秒重渲染 10 次。
- 影响面：有逐字时间的歌的曲库歌词和全屏歌词的流畅度。
- 修复：☑ 根因修复（与本档案同一提交；只有正在逐字点亮的当前行拆字，其余行原样输出） ☑ 自动化测试（`app/src/useKaraoke.test.ts`）
- 清理条件：无临时兼容层
