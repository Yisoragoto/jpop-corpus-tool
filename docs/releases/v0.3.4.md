### macOS 安装包
- 第一次附带 macOS 安装包 `JPOP.Corpus.Tool_0.3.4_macOS_arm64.dmg`（macOS 14+，Apple Silicon）。
- Mac 版现在和 Windows 版功能对齐：首页、资料库（关系网、时间轴、词云）、全屏歌词、卡拉 OK 与打轴、逐字歌词获取、检索与试听、分析与存档、词典、Anki 制卡与 Anki 页、刮削、导入、检查更新。两端共用同一个 Rust 核心和同一种库。
- 安装包没有经过 Apple 签名和公证。第一次打开会被拦下：到「系统设置 → 隐私与安全性」点「仍要打开」，或者在终端执行 `xattr -dr com.apple.quarantine "/Applications/JPOP Corpus.app"`。

### 逐字歌词、卡拉 OK 与打轴
- 全库一键补逐字歌词，导入后默认自动补；来源有 QQ 音乐、酷狗、AMLL 社区库、LRCLIB、网易云，可逐个开关。只有歌名、歌手、时长对得上、正文和现有歌词至少 97% 一致时才自动采用，拿不准的进待复核；手动导入、编辑、打轴过的歌词不会被覆盖。
- 单首可以「搜索逐字歌词」，先看候选的来源、真实逐字行数和正文预览再采用。
- 新增卡拉 OK 模式：两行歌词 KTV 式交替，前奏显示歌名和制作人员，长间奏后倒数。
- 新增打轴：按住或点按空格逐字打点，波形上拖动边界、微调、撤销重做、慢放；存成受保护的新版本。
- 只有行时间的歌整行高亮，不再拿字数均摊冒充逐字。

### 资料库与词云
- 音乐人档案改成歌手页：大照片顶栏，概览 / 作品 / 成员与合作 / 时间轴四页。概览列出这个人的每一首歌（横条或大封面），下面是专辑和 EP。
- 刮削新增「专辑信息」：补发行类型和整张碟的曲目数。
- 词云跳到检索时带上词云的范围（歌手、年份、词性）；看例句时也能查词典，例句上限从 24 提到 1000。词云的字体、词数、配色、仅日文、去虚词收进「设置」弹层。
- 全屏歌词查词时先显示这个词在语料里出现几次、几首歌、几位歌手、哪些年份。

### 其他
- 修复：点歌词里的词查词时不再跳播放进度；点过按钮后快捷键仍然可用。
- 窗口背景改用系统亚克力，切换窗口时不再忽明忽暗。
- 字体导入支持 zip；联网时读 Windows 系统代理。
- README 重写，补上方法说明（基于语料库语言学）。

### 升级须知
- 从 0.3.3 升级时，曲库结构会由 20261020 增量升级至 20261022，保留已有记录。升级后的库不能再用 0.3.3 打开。
- Windows 用户在程序里点「立即更新」即可；macOS 用户下载新的 `.dmg` 覆盖安装。

### macOS installer
- The first release with a macOS installer: `JPOP.Corpus.Tool_0.3.4_macOS_arm64.dmg` (macOS 14+, Apple Silicon).
- The Mac app now matches the Windows app: home, the library (graph, timeline, word cloud), full-screen lyrics, karaoke and the timing editor, word-timed lyric fetching, search and auditioning, analysis and archives, dictionaries, Anki mining and the Anki page, scraping, import and update checks. Both share one Rust core and one library format.
- The app is not signed or notarized by Apple, so the first launch is blocked: click **Open Anyway** under **System Settings → Privacy & Security**, or run `xattr -dr com.apple.quarantine "/Applications/JPOP Corpus.app"` in Terminal.

### Word-timed lyrics, karaoke and the timing editor
- Fill in word-timed lyrics for the whole library in one click, and automatically after import by default. Sources: QQ Music, Kugou, the AMLL community database, LRCLIB and NetEase, each of which can be switched off. A match is adopted automatically only when title, artist and duration line up and the text agrees at least 97 % with the existing lyrics; uncertain ones go to review. Lyrics you imported, edited or timed by hand are never overwritten.
- For a single song, **Search word-timed lyrics** shows each candidate's source, number of truly word-timed lines and a text preview before you adopt it.
- New karaoke mode: two lines alternating KTV-style, title and credits during the intro, a countdown after long breaks.
- New timing editor: hold or tap Space per character, drag boundaries on the waveform, nudge, undo/redo, slow playback; saved as a protected new version.
- Songs with line timing only highlight whole lines instead of faking word timing from character counts.

### Library and word cloud
- Artist profiles are now artist pages: a large photo header and Overview / Works / Members & collaborators / Timeline tabs. Overview lists every song by the artist (as a list or as large covers), with albums and EPs below.
- Scraping can now fill in album details: release type and track count.
- Jumping from the word cloud to search keeps the cloud's scope (artist, years, part of speech); examples can be looked up in the dictionary, and the example limit goes from 24 to 1000. Word-cloud font, word count, colours, Japanese-only and function-word filtering moved into a Settings popover.
- Looking a word up in full-screen lyrics first shows how often it occurs in your corpus, in how many songs, by how many artists and in which years.

### Other changes
- Fixed: clicking a word in the lyrics to look it up no longer moves playback; shortcuts keep working after you click a button.
- The window backdrop now uses system Acrylic and no longer flickers when you switch windows.
- Font import accepts zip files; network access follows the Windows system proxy.
- Rewrote the README, with a methods section on the corpus-linguistics basis.

### Upgrading
- Upgrading from 0.3.3 updates the library schema from 20261020 to 20261022 while preserving existing records. An upgraded library can no longer be opened by 0.3.3.
- On Windows, choose **Update now** in the app; on macOS, download the new `.dmg` and install over the old one.

**Recommended downloads: Windows `JPOP.Corpus.Tool_0.3.4_x64-setup.exe`, macOS `JPOP.Corpus.Tool_0.3.4_macOS_arm64.dmg`.**
