### Update channels · stable / debug
- The app follows stable releases by default. Switch channels under Settings → Updates & system → Update channel.
- Debug follows each push to main and recognizes new builds even when the version stays the same. A confirmation explains the stability risk and that the app will not switch back to stable automatically.
- Fixed the `plugin:dialog|message not allowed by ACL` error when switching to debug in the earlier 0.3.3 build. The confirmation dialog now has the required native permission.
- Downloads still verify the source and SHA-256; debug builds also verify the file size. Switching channels will not install a lower version.

### Keyboard controls, content identity and batch tools
- Fixed global Space shortcuts swallowing button actions. Focused import and playback buttons can now be activated with Space.
- Added ISRC, MusicBrainz IDs, label metadata and source records. Audio content fingerprints remain unchanged when a file is renamed.
- Added the `jp` CLI, available to build from source. It shares library path resolution with the app and supports scanning, importing, tokenization, metadata scraping and Anki text export.
- Added translation, version, architecture and real-window interaction checks. Tests requiring external hardware or data are explicitly marked as skipped.

### Upgrading
- Upgrading from 0.3.2 adds schema changes from 20261019 to 20261020 while preserving existing records.
- This release replaces the earlier 0.3.3 build. If you installed that build, the app will not offer another build with the same version as an update; download this one, install over it manually and reopen the app.
- The macOS client remains under development and validation. This release does not indicate that all macOS features are complete or fully verified.

**Recommended download: `JPOP.Corpus.Tool_0.3.3_x64-setup.exe`.**
