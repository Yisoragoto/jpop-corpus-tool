# JPOP Corpus Tool 0.3.3

本次提供 Windows 安装包：`.exe` 或 `.msi` 任选一种。

- 更新支持 stable / debug 两条轨道，默认跟随正式版。可在设置里选择滚动 debug；同版本的不同调试构建也能被识别。
- 更新包继续校验来源和 SHA-256，debug 额外校验字节数；切换轨道不会安装更低版本。
- 新增 `jp` 命令行入口，与应用共用曲库目录解析，支持扫描、导入、补分词、刮削和 Anki 文本导出。
- 增加 ISRC、MusicBrainz 身份、厂牌等元数据及来源记录；导入音频时计算文件内容指纹，改名后仍可识别相同音频内容。
- 修复全局空格热键抢占按钮操作的问题，聚焦导入或播放按钮后可用空格激活。
- 增加架构、翻译、颜色、版本及真实窗口交互检查，并明确列出依赖外部设备或数据的测试。

macOS 客户端仍在开发和验证中，本次发布不代表 macOS 功能已经全部完成或验收。
