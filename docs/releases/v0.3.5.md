### 语料分析
- 分析工具向专业语料库软件看齐：离散度（DP、Juilland's D、ARF）、搭配的 MI3 / z 值 / ΔP、关键词的显著性检验、不跨行的 N-gram、词汇丰富度（MATTR、MTLD、Yule's K）和文字构成。分析页重做并分页。
- 新增形态标注层：每个词记下日文词性、活用型、活用形、读音和规范形；已有歌词在启动后后台补标，不改原有分词。检索和搭配可以按读音或规范形匹配，按活用形筛选；分析页新增「活用 · 写法」。
- 检索页新增 CQL 模式（Sketch Engine / CQP 的子集），输入时就检查语法。结果可以按年份、按歌手分解，搭配可以画成网络。

### 歌词与播放
- 每首歌记下见过的所有歌词来源（自己导入或编辑的、音频旁的同名文件、内嵌歌词、在线获取的），默认按「自己 > 同名文件 > 内嵌 > 在线」选用，也可以手动指定；能整体调偏移。认 `.srt` 和带语言后缀的翻译文件，翻译按时间对齐。
- 歌词跟随改成插值的播放时钟，切行更准；手动滚动歌词会暂停跟随，点「回到当前行」恢复。
- 音频文件和曲目分开记录：重新扫描时没变的文件直接跳过（实测 252 个文件从 4.1 秒降到 30 毫秒），改过的文件安全刷新、不覆盖你改过的字段；查重先看 ISRC 和 MusicBrainz ID，再看歌名、歌手、版本标记和时长。
- 卡拉 OK 字幕样式可以自己调：字体、字号、粗细、没唱 / 唱过两套颜色、描边、发光、立体阴影、两行错开。预设有「经典蓝」「粉色像素风」「简洁」，默认是「简洁」。设置页和卡拉 OK 顶栏里都能改，两端字段相同。

### Corpus analysis
- Analysis tools closer to dedicated corpus software: dispersion (DP, Juilland's D, ARF), MI3 / z-score / ΔP for collocations, significance tests for keyness, N-grams that never cross a line, lexical richness (MATTR, MTLD, Yule's K) and script composition. The Analytics page is rebuilt with tabs.
- A new morphology layer stores Japanese part of speech, conjugation type and form, reading and normalized form for every token. Existing lyrics are annotated in the background after startup without changing the original tokens. Search and collocations can match by reading or normalized form and filter by conjugation form; Analytics gains a Conjugation & spelling tab.
- The search page has a CQL mode (a subset of Sketch Engine / CQP) that checks syntax as you type. Results can be broken down by year or artist, and collocations can be drawn as a network.

### Lyrics and playback
- Every lyric source a song has seen is recorded (your own import or edit, a same-name file next to the audio, embedded lyrics, online). The default follows "yours > same-name file > embedded > online", you can pick one by hand, and set an overall offset. `.srt` files and language-suffixed translation files are recognised, and translations are aligned by time.
- Lyrics follow an interpolated player clock, so line changes are more accurate. Scrolling the lyrics by hand pauses following until you choose **Back to current line**.
- Audio files are tracked apart from tracks: rescans skip unchanged files (252 files went from 4.1 s to 30 ms), changed files refresh safely without overwriting fields you edited, and duplicate detection checks ISRC and MusicBrainz IDs before title, artist, version markers and duration.
- Customizable karaoke subtitles: font, size, weight, unsung and sung colours, outline, glow, 3D shadow and staggered lines. Presets are Classic blue, Pink pixel and Plain; Plain is the default. Change it in Settings or from the karaoke toolbar; both clients use the same fields.

### Interface
- The Windows UI is restyled after WinUI 3 / Fluent 2, with a new light theme.
- One-click scraping: identify songs → artist photos → covers → album details in one background job.
- The word cloud's song panel opens from every corpus page.

### macOS
- Opens a corpus copied from Windows directly (⌘O); a banner explains missing audio and images and offers to add a music folder or fill covers online.
- English UI, switchable navigation and new icons; fixes for opening a library, a CQL freeze and the lyrics stage layout.
- No more grey toolbar band in full screen; the word-cloud backdrop reaches the top of the window; dragging the graph or timeline no longer drags the window.
- A play queue with previous / next track, plus fixes for idle CPU use, media keys and races when switching libraries or calibrating.

### Upgrading
- Upgrading from 0.3.4 updates the library schema from 20261022 to 20261101 while preserving existing records. An upgraded library can no longer be opened by 0.3.4; back up `corpus.db` first if you may want to go back.
- On Windows, choose **Update now** in the app; on macOS, download the new `.dmg` and install over the old one.

**Recommended downloads: Windows `JPOP.Corpus.Tool_0.3.5_x64-setup.exe`, macOS `JPOP.Corpus.Tool_0.3.5_macOS_arm64.dmg`.**
