# 卡拉 OK 与打轴

曲库页歌词右上角（或全屏歌词右上角）点「卡拉 OK」进入。这首歌没在放时会从头开始放。

## 卡拉 OK

- 背景是这首歌的封面：一张放大虚化铺满，一张清楚的摆在中间。
- 歌词两行压在底部，KTV 式上下交替：第 1、3、5… 行在上、靠左，第 2、4、6… 行在下、靠右。唱完一行，它的位置换成后面第二行。
- 有逐字时间的行逐字变色；没有逐字时间、只有行时间的行到点整行变色，不按字数均摊。完全没有时间的行不显示。
- 第一句前、以及停顿 4 秒以上的间奏之后，入句前 3 秒倒数（●●● → ●● → ●）。
- 前奏时显示歌名、歌手和作词作曲编曲。
- 空格播放/暂停，Esc 退出，⛶ 窗口全屏。

逐字时间和普通歌词用的是同一份验证过的时间轴（`charTimeline`），规则见 [word-lyrics.md](word-lyrics.md)。

以后要加的 MV / 视频背景替换的是背景那一层（`.ktv-bg`），歌词层不变。

## 打轴

卡拉 OK 页右上角「打轴」。

**单位。** 已经有逐字时间的行，原样用来源给的切分和时间。没有时间的字按拍切开：一个字一个单位，拗音小字（ゃゅょ…）并进前一个字，空白和标点跟着前一个字，连在一起的拉丁字母和数字算一个词。切分可以用「拆开」「和后一个合并」改。

**打点。** 空格键：

| 模式 | 做法 |
|---|---|
| 按住（默认） | 按下 = 这个字开始唱，松开 = 唱完。结尾和字之间的停顿都打得出来 |
| 点按 | 每个字按一下，前一个字唱到这一下为止；一行最后一个字按住、松开记结尾 |

打完一个字自动跳到下一个，行尾跳到下一行。重打一个字时，同一行后面比它早的旧时间会清掉，不留下倒退的时间。

按键那一刻直接问一次播放引擎的位置，扣掉往返时间的一半，再扣掉「按键提前量」（人的反应加声卡缓冲，默认 150 ms，可调，打出来整体偏晚就调大）。0.5× / 0.75× 慢放时记下来的仍是原曲时间。

**手动调。**

- 下方波形显示选中的那一行，每个字一个色块。拖色块边缘改时间；连唱的两个字之间只有一条线，拖一下两边一起动，不会越过邻居。点色块选中，点空白处从那里放。
- 开始、结尾各有 ±10 ms / ±100 ms 按钮，也可以直接输入时间（`1:23.456` 或秒数）。

**快捷键。**

| 键 | 作用 |
|---|---|
| 空格 | 打点 |
| Enter / P | 播放 / 暂停 |
| R | 从这一行前 1.5 秒开始放，光标回到行首 |
| ← → | 上一个 / 下一个字 |
| ↑ ↓ | 上一行 / 下一行 |
| `[` `]` | 开始 −/+ 10 ms（Shift：100 ms） |
| `,` `.` | 结尾 −/+ 10 ms（Shift：100 ms） |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+S | 保存 |
| Esc | 回到卡拉 OK（有没保存的改动会先问） |

**每行状态。** 逐字（每个字都有起止，播放会逐字点亮）/ 未完成（打了一部分，或者结尾晚于下一行的开始、超出音频长度——能存，播放时这一行整行高亮）/ 未打 / 时间倒退（存不了）。

## 保存

存成新的一版歌词（`lyrics_save_timing`，见 `jp-app/src/lyrics.rs` 的 `save_timed_lines`）：

- 只改时间不改字。行数和每行正文必须和库里现在的一样，否则说明打开打轴后歌词换过了，拒绝保存。
- 逐字时间写成增强 LRC（毫秒精度，字之间有停顿时写 `<结尾><开始>` 两个时间），落盘到 `raw/lyrics_lrc/{id}.lrc`。入库后就是普通的 `lrc` 单位，播放器按原来的规则验证，没有第二套时间轴。
- 有单位的行，行首时间取第一个字的开始。
- 版本来源记 `manual_edit`、`timing_origin = manual`，修订历史记 `lyrics_timed`（「手动打轴」）。批量补逐字歌词不会覆盖它。
- 旧版进「来源与版本」，可以恢复。分词校正按原文套回。以前只记了起点的手动校准（查词跳转用）原样保留。

- `app/src/karaoke.test.ts`：切分、打点两种模式、重打清理、边界联动、拆开合并、状态判断、KTV 交替和倒数。
- `jp-app` 的 `manual_timing_becomes_a_protected_version_the_player_accepts`：保存后落盘文件逐字节确定、读回来时间一致，`display_timeline` 认作逐字，版本受保护，起点校准保留；正文变了、重叠、倒退都拒绝且不留版本。
- `jp-audio` 的 `peaks_take_the_loudest_sample_of_each_bucket_across_channels`：波形轮廓。
