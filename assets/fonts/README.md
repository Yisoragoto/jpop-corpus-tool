# Bundled Fonts

This directory contains fonts bundled for the desktop app so users do not need
to install them manually.

- `KleeOne-SemiBold.ttf`
  - Family name in Qt: `Klee One`
  - Source project: https://github.com/fontworks-fonts/Klee
  - License: SIL Open Font License 1.1, see `OFL-Klee.txt`

- `LXGWWenKai-Regular.ttf`
  - Family name in Qt: `LXGW WenKai`
  - Source project: https://github.com/lxgw/LxgwWenKai
  - License: SIL Open Font License 1.1, see `OFL-LXGWWenKai.txt`
